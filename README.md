# Senlimicy Custom Crafts
A datapack for my Minecraft server - [Senlimicy](https://modrinth.com/server/senlimicy).
This datapack adds features that, in my opinion, should be included in vanilla Minecraft. You can view all the crafting recipes added by this data pack [here](https://sites.google.com/view/senlimicy/mechanics/crafts).

Based on [Increased Rails Recipe Output](https://modrinth.com/datapack/increased-rails-recipe-output) datapack.
